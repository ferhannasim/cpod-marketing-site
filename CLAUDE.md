# CLAUDE.md

This repo holds two separate sites, each in its own top-level directory:

- **`dropship/`** — the existing site (Next.js marketing site + legacy Shopify theme
  reference). All prior repo-root code was moved here on 2026-07-21. See
  `dropship/CLAUDE.md` for its full guidance and `dropship/README.md` for the Next.js app.
- **`custy/`** — the new "custy" site: a Next.js marketing site (faithful port of
  custyapp.com) plus a live pull of the legacy Shopify Horizon theme kept as untracked
  local reference. See `custy/CLAUDE.md` for its full guidance and `custy/README.md` for
  the Next.js app.

Run commands (pnpm, next, shopify CLI) from inside the relevant site directory, not the
repo root.
